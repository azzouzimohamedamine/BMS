# Methodology

All numbers quoted here come from `results/metrics/*.csv` produced by the scripts in `scripts/`.

## 1. Data and reference definitions
* Four CALCE SP20-1 files → standard schema (`configs/dataset_config.yaml`): time [s], voltage [V], current [A] (charge > 0).
* Segmentation by current sign (|I| < 20 mA = rest, min. 10 min). The **main discharge** of each test is used for SOC.
* **SOC reference (CALCULATED, not measured):** `SOC_ref(t) = 1 − ∫|I|dt / Q_dis,total` over the main discharge; 100 % = start of the discharge (after a 2 h rest, V ≈ 4.16–4.18 V), 0 % = 2.5 V cut-off of *that* test. Consequences: it is normalised by each test's own delivered capacity (this hides the temperature dependence of capacity), it inherits current-sensor error, and it is only valid for the discharge branch (the 25/45 °C charge phases are incomplete).
* Uniform resampling at 20 s (linear interpolation). Metrics exclude the first 10 min of each test for **all** models (sequence-window warm-up) so that every model is scored on identical samples.

## 2. SOC estimators
| Method | Implementation | Inputs | Notes |
|---|---|---|---|
| Coulomb counting | `models/soc/coulomb.py` | I, SOC₀, **prior** capacity | Capacity = delivered capacity of the 25 °C test (2.157 Ah). Using each test's own capacity would be circular (error ≡ 0). Also run with a wrong SOC₀ = 70 %. |
| EKF | `models/soc/ekf.py`, `battery_models/ecm.py` | V, I | 1-RC Thévenin ECM, state [SOC, V₁]. R₀ from the rest→discharge voltage step; R₁, τ from the first 20 min of the discharge voltage; pseudo-OCV from the 0.1 A discharge corrected by i·(R₀+R₁). Parameters identified on 25 °C only. |
| Random Forest | `models/soc/ml.py` | V, I, causal V moving average (10 min), 10-min ΔV | blocked CV grid search |
| Gradient boosting | `HistGradientBoostingRegressor` | same | **Not XGBoost** (package unavailable offline). The code uses XGBoost automatically if installed. |
| LSTM / GRU | `models/soc/rnn_numpy.py` | 30-step (10 min) windows of (V, I) | Pure NumPy, manual BPTT, Adam, early stopping; gradients validated by finite differences (`tests/test_rnn_gradients.py`). Hidden size 16. |

Temperature is **not** a model input (no temperature measurement exists); temperature influence is studied through cross-condition experiments.

## 3. Validation protocol
* Test conditions are always unseen by the fitted models (cross-temperature, and cross-rate with the 1 A test). Protocols: 25→{0,45,1 A}, {25,45}→0, {0,25}→45, {0,45}→25, {0,25,45}→1 A.
* Hyper-parameters: grid search with **blocked CV** (5 contiguous blocks per training condition, gap = window length around block edges → no leakage between overlapping/auto-correlated samples). The CV error (≈ 7–8 SOC points) is much larger than the test error because every held-out block forces extrapolation along the SOC axis; it is used for model *selection* only.
* RNNs: early stopping on a contiguous validation block (15 %, with gap) of each training condition. Scalers fitted on training data only.
* Seeds fixed (42). Models persisted in `models/` (git-ignored, regenerated by the scripts).
* Noise robustness: **simulated** Gaussian noise / current bias added to the real test signals (levels in `configs/model_config.yaml`); EKF noise covariance is not re-tuned.
* Post-hoc change (disclosed): after observing that LSTM/GRU collapse under noise, a variant with a floor on the input standard deviation (`*_sf`: 0.05 V, 0.1 A) was added. The original variant is kept in all tables. No hyper-parameter was tuned on test data.

## 4. SOH, RUL
Implemented as guarded pipelines (`models/soh`, `models/rul`) that raise `InsufficientDataError` unless: ≥ 20 (SOH) / ≥ 30 (RUL) cycles, verified nominal capacity, and (RUL) an observed crossing of the EOL threshold. On the CALCE files used here they correctly refuse (1 cycle per file, nominal capacity unverified). The unit tests exercise them on explicitly synthetic arrays for software correctness only; no synthetic result is reported.

## 5. Fault diagnosis
* Real data: windowed features (60 s, hop 30 s) → robust-z threshold detector, Isolation Forest, One-Class SVM (thresholds = 99.5th percentile of training scores), plus a persistence rule for a frozen voltage channel. Fitted on 0 °C + 45 °C, applied to unseen 25 °C and 1 A data. Detections are **statistical anomalies**.
* Simulation: five synthetic fault types injected into the real 25 °C signal (4 events × 300 s, 4 magnitudes). Used only to benchmark detectors; **never** presented as real faults.
* Diagnostic layer (`models/fault/diagnosis.py`): measurement involved, severity, agreement-based confidence, interpretation (flags probable protocol transitions), recommended investigation, provenance.
* Autoencoder and supervised classifiers were **not** implemented: no labels and too little structured data to justify them.
